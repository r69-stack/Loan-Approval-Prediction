# 🏦 Loan Approval Prediction System

An end-to-end Machine Learning project that predicts whether a loan application will be approved based on applicant information.

## Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Hyperparameter Tuning
- Streamlit Web Application
- Loan Approval Prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## Dataset Features
- Gender
- Married
- Dependents
- Education
- Self Employed
- Applicant Income
- Coapplicant Income
- Loan Amount
- Loan Amount Term
- Credit History
- Property Area

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
